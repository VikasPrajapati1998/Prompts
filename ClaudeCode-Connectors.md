# Claude Code – Connectors, MCP Servers & Skills

A curated list of tools, MCP servers, and skills that extend Claude Code's capabilities across UI development, codebase analysis, software engineering workflows, application testing, and customer discovery.

| # | Tool / Connector | Primary Purpose | Key Capabilities |
|---|---|---|---|
| 1 | **[21st MCP](https://21st.dev/)** | UI Component Generation | Provides ready-made UI components and design resources that Claude Code can use to build modern application interfaces. |
| 2 | **[Graphify](https://github.com/graphify)** | Codebase Knowledge Graph | Analyzes the entire codebase and creates a knowledge graph to understand relationships between files, modules, functions, and dependencies. |
| 3 | **Compound Engineering** | End-to-End Development Workflow | Provides a structured software development workflow covering planning, implementation, code review, testing, and documentation. |
| 4 | **Playwright Skill** | Application Testing & Automation | Automates browser interactions and tests complete application workflows, including UI interactions, user journeys, and end-to-end scenarios. |
| 5 | **Harvey** | Customer Discovery & Lead Generation | Helps identify potential customers and business opportunities for your application through customer discovery and lead generation. |

## Key Objectives

- **UI Development:** Accelerate frontend development using reusable UI components and design resources.
- **Codebase Understanding:** Build a comprehensive understanding of the application's architecture and code relationships.
- **Development Lifecycle:** Establish a structured workflow from planning and implementation to testing and deployment.
- **Automated Testing:** Validate complete application workflows through browser automation and end-to-end testing.
- **Customer Acquisition:** Identify potential customers and discover opportunities to promote and grow the application.

## Integration Approach

Integrate these tools into Claude Code through MCP servers, skills, and supported integrations.

The objective is to establish an AI-assisted development environment in which Claude Code can understand the codebase, generate UI components, manage the development lifecycle, test application workflows, and support customer discovery.

# Free Open Source Software

## Video & Media Editing

### [OpenCut](https://github.com/OpenCut-app/OpenCut)
A browser-based, open-source video editor built with privacy in mind.

- **Platform**: Web-based (works on any platform)
- **Installation**: None required
- **Account**: Not required
- **Privacy-focused**: No tracking or data collection
- **License**: Open Source

## AI & Productivity

### [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm)
A desktop application and self-hostable platform for working with AI and large language models locally.

- **Platform**: Desktop (Windows, macOS, Linux)
- **Installation**: Local installation or self-hosted
- **Account**: Not required
- **Features**: Chat with documents, run AI models, work with LLMs entirely offline/on your own machine
- **Privacy-focused**: All data stays on your machine

### [Handy](https://github.com/cjpais/Handy)
A free, open-source alternative to WhisperFlow for offline speech-to-text transcription.

- **Platform**: Desktop (cross-platform)
- **Installation**: Required
- **Account**: Not required
- **Features**: System-wide speech-to-text - press a keyboard shortcut, speak, and text appears at your cursor
- **Privacy-focused**: 100% offline, no cloud processing, no subscription, no copy-paste required

## Audio

### [Nuclear](https://github.com/nukeop/nuclear)
An open-source desktop music player that aggregates music from multiple online sources.

- **Platform**: Desktop (cross-platform)
- **Installation**: Required
- **Account**: Not required
- **Features**: Multi-source streaming, ad-free experience
- **Privacy-focused**: No ads, no tracking, no telemetry, no data collection. Fully auditable open-source code

## Screen Recording

### [Cap](https://github.com/CapSoftware/Cap)
A cross-platform screen recorder built for asynchronous work and collaboration.

- **Platform**: Native apps for macOS, Windows, and Linux
- **Installation**: Required
- **Account**: Not required
- **Features**: Record and edit screen recordings quickly with three distinct workflows in one app
- **Use case**: Ideal for sharing work asynchronously

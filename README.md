# Technology Documents & Prompts Repository

A curated collection of technical guides, cheat sheets, and reusable prompts covering AI/ML infrastructure, quantum computing, security auditing, development workflows, productivity tools, and other technology topics.

This repository serves as a personal knowledge base for offline reference and quick access to practical, command-focused documentation.

---

## 📖 How to Use

Browse the repository files directly — each document is self-contained with installation, usage, and reference sections.

- **Guides & tutorials** — Read as offline documentation
- **Prompts** — Copy into Claude Code or similar agents
- **Cheat sheets** — Quick command lookup
